## 三、横贯能力标签

这些标签可以同时挂在任意 Lesson 和 KnowledgeNode 上，不另建题型课程，也不改变 Course 权重。

| 标签 | 中文 | 输出要求 |
| --- | --- | --- |
| `SOURCE` | 史料判读 | 来源、时代、信息、价值、局限 |
| `JUDOU` | 古文句读 | 断点、实体识别、句法依据 |
| `TRANSLATION` | 文献翻译 | 实词、专名、制度、句义 |
| `MAP` | 地图与空间表达 | 定位、方向、古今地名、路线/水系图 |
| `CHRONOLOGY` | 时间序列 | 阶段、先后、同步变化 |
| `CHANGE` | 演变分析 | 原因、过程、结果、尺度 |
| `COMPARE` | 制度/区域比较 | 比较维度和异同机制 |
| `EVIDENCE` | 史源评价 | 证据能证明什么、不能证明什么 |
| `ARGUMENT` | 论述 | 中心判断、证据、层次、结论 |
| `ACADEMIC` | 学术史与前沿 | 学者、著作、问题、方法、争议 |

## 四、结构门禁

- 课程顺序由本表和《课程总纲》共同控制，Universal 不得反向改写。
- Lesson 只有在证据矩阵中的教材、原典、地图和题目状态达到要求后，才可从 `DRAFT` 变为 `TEACHABLE`。
- `REVIEW` 单元不强行归入任何章节；不以降低审计问题数量为目标。
