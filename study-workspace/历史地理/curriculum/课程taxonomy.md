> 生效日期：2026-08-15  
> 主控文件：`C:\Users\30374\Documents\ChatGPT\考研\课程总纲.md`  
> 用途：为考纲、资料内容单元、真题和教学产物提供稳定章节编号。本文只定义分类边界，不改变课程范围和权重。

## 一、分类原则

1. 每个内容单元只能有一个 `primary_chapter`，可以有零至三个 `secondary_chapters`。
2. 按“该单元主要回答什么问题”分类，不按孤立关键词分类。例如出现“黄河”的材料，如果主要讨论治河制度，归 `HG-11`；如果讨论河道变迁，归 `HG-06`。
3. 先判断知识对象，再判断时代和能力。时代只作为标签，不代替专题章节。
4. 真题同时挂接知识章节与能力标签；不得只按题型或年份归档。
5. 无法确定主问题、跨越四章以上或只有目录残片的单元进入 `REVIEW`，不得默认塞入第1章。
6. 回忆真题只记录命题观察；自编资料只记录候选知识，不自动成为事实证据。

## 五、内容单元最小字段

后续重分5596个内容单元时，每条至少记录：

`unit_id / primary_chapter / secondary_chapters / skills / source_type / source / locator / verification / confidence / review_note`

允许值：

- `verification`：`verified / needs_review / disputed / unavailable`
- `confidence`：`high / medium / low`
- `source_type`：`fudan_official / primary_source / academic / core_textbook / notes / recalled_exam / self_compiled`

## 六、抽样验收

- 每章随机抽10条；不足10条则全查。
- 主章节正确才算通过，次章节遗漏记一般问题。
- 任一章主分类准确率低于95%，返回 taxonomy 或分类规则修订，不进入正式 wiki。
- `REVIEW` 数量单独报告，不以强行归类来提高表面准确率。
