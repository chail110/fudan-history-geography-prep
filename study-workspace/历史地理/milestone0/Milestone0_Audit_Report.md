# Milestone 0 Audit Report

> 审计日期：2026-08-15
>
> 方法：重新读取复旦2024大纲原始HTML及四张原图；独立读取复旦新站课程、教师、毕业训练、CHGIS数据与版权原页；只读比对本地四份Milestone 0基线文件。搜索摘要仅用于定位原页，不作为最终裁决证据。

## P0错误

### P0-1｜CHGIS数据被笼统标为OPEN，不符合官网用户协议

- **结论**：CHGIS说明页可以公开读取，但数据获取和使用不是无条件OPEN。官网V2.0用户协议写明：数据限非商业学术研究与教育；主要居住或主要在中国境内使用者需要得到复旦大学中国历史地理研究中心许可；不得从第三方取得或向第三方提供数据；成果使用须注明来源。
- **原始来源**：[CHGIS版权声明](https://yugong.fudan.edu.cn/CHGIS/bqsm.htm)、[数据下载页](https://yugong.fudan.edu.cn/CHGIS/sjxz.htm)。
- **本地文件位置**：`复旦历史地理教材证据表.md` 的“CHGIS”行；`Material_Gap_Report.md` 的“核心缺口”第6项及“OPEN”小节。
- **当前写法**：把CHGIS整体写成`OPEN`，容易被理解为数据可以直接下载、保存和再利用。
- **建议处理**：拆开“公开网页/元数据”和“实际数据集”。网页与说明为OPEN；数据集记为`PARTIAL / 需按协议取得许可`，在许可确认前不下载、不入库。

### P0-2｜《中国历史地图集》“实际课程使用=是”超出证据

- **结论**：2026届毕业典礼原页足以证明该书出现在史地所学生训练场景，支持S+“实际训练材料”；但没有课程大纲、reading list或教师说明证明它是某门课程的指定用书。
- **原始来源**：[2026届研究生毕业典礼](https://yugong.fudan.edu.cn/info/1081/21311.htm)。
- **本地文件位置**：`复旦历史地理教材证据表.md` 的《中国历史地图集》行，“是否实际课程使用”列。
- **当前写法**：`是，有复旦官方训练叙述`。
- **建议处理**：改为“课程指定使用未证实；复旦官方确认其出现在学生训练场景”。保留S+，但S+理由只落在“实际训练”，不落在“课程指定教材”。

### P0-3｜CHGIS“实际课程使用=是”混合了三种结论

- **结论**：现有直接证据分别支持：①2024大纲考查“历史地理信息系统”，但未点名CHGIS；②2026届毕业典礼确认学生实际使用CHGIS；③孙涛主讲“数字地图制图与应用”，但教师页没有说该课程使用CHGIS。不能据此写成“CHGIS实际课程使用=是”。
- **原始来源**：[2024大纲](https://yugong.fudan.edu.cn/info/1091/7581.htm)、[2026届研究生毕业典礼](https://yugong.fudan.edu.cn/info/1081/21311.htm)、[孙涛教师页](https://yugong.fudan.edu.cn/info/1461/12711.htm)。
- **本地文件位置**：`复旦历史地理教材证据表.md` 的CHGIS行。
- **当前写法**：对应课程写“历史GIS；数字地图制图与应用”，课程使用写“是”。
- **建议处理**：分别标注“742考点=历史地理信息系统”“实际训练工具=CHGIS”“相关课程存在，但CHGIS是否为该课程工具未证实”。

## P1缺口

### P1-1｜部分证据链接指向已404的旧站路径

- **结论**：若干`/info/1006/`、`/info/1113/`、`/info/1114/`旧链接当前返回404，新站已有可访问的迁移页。
- **原始来源**：复旦新站对应页面，例如[李晓杰](https://yugong.fudan.edu.cn/info/1451/12531.htm)、[王哲](https://yugong.fudan.edu.cn/info/1461/12681.htm)、[鲍俊林](https://yugong.fudan.edu.cn/info/1461/12671.htm)、[2009课程通知](https://yugong.fudan.edu.cn/info/1091/11661.htm)。
- **本地文件位置**：三份Milestone 0基线文件中的相应外链。
- **当前写法**：事实大体正确，但部分链接不能重新打开。
- **建议处理**：在本次最小修正中替换已确认的新站URL；未找到迁移页的链接保留并标“待迁移”，不以搜索摘要补造原文。

### P1-2｜同名课程与同名专著仍缺直接书单关系

- **结论**：《中国历史人文地理》《中国历史自然地理》《中国人口史》《中国移民史》《中国历史民族地理》存在课程或研究方向证据，但尚无公开reading list证明同名著作是指定教材。
- **原始来源**：[王哲](https://yugong.fudan.edu.cn/info/1461/12681.htm)、[鲍俊林](https://yugong.fudan.edu.cn/info/1461/12671.htm)、[安介生](https://yugong.fudan.edu.cn/info/1451/12381.htm)、[2009课程通知](https://yugong.fudan.edu.cn/info/1091/11661.htm)。
- **本地文件位置**：`复旦历史地理教材证据表.md` 对应各行。
- **当前写法**：已经标注“课程同名、指定教材未证实”。
- **建议处理**：维持现状；后续只在出现课程大纲、reading list或教师明确说明时升级。

### P1-3｜五种首批教材尚未完成逐本馆藏与正版购买路径核验

- **结论**：现有`LIBRARY / PURCHASE`是类别判断，不是已经确认某馆有书或某平台有货。
- **原始来源**：[复旦图书馆馆藏目录说明](https://library.fudan.edu.cn/14/list.htm)。
- **本地文件位置**：`Material_Gap_Report.md`、`复旦历史地理核心书架.md`。
- **当前写法**：已明确“尚未逐本确认馆藏”，没有误报拥有状态。
- **建议处理**：在获取队列中逐项写“馆藏待查/正版渠道待核”，不虚构库存或购买链接。

## 证据不足

### E-1｜《水经注》课程指定底本未知

- **结论**：李晓杰教师页直接证明存在研究生课程“《水经注》研读”，并列出其《水经注校笺图释》系列成果；未公开该课程指定哪一种完整整理本。
- **原始来源**：[李晓杰教师页](https://yugong.fudan.edu.cn/info/1451/12531.htm)。
- **本地文件位置**：教材证据表、核心书架的《水经注》条目。
- **当前写法**：已经注明“具体整理本未证明/版本待比对”。
- **建议处理**：不得指定某出版社版本为“复旦教材”；获取队列单列底本调查。

### E-2｜《中国历史地图集》的S+只限“实际训练”，不含“指定教材”

- **结论**：官方毕业叙述明确出现“翻检《中国历史地图集》”，足以支持训练场景；不能外推课程、频率或考法。
- **原始来源**：[2026届研究生毕业典礼](https://yugong.fudan.edu.cn/info/1081/21311.htm)。
- **本地文件位置**：教材证据表、核心书架。
- **当前写法**：等级可保留，但字段需按P0-2纠正。
- **建议处理**：以后所有S+结论写明究竟是课程、指定阅读、考试还是训练场景。

## Audit Gate结论

发现3项P0：两项“训练场景/相关课程”被误填为“实际课程使用=是”，以及CHGIS数据被错误笼统标为OPEN。它们不推翻六本官方参考书和首批五种获取顺序，但会影响证据强度与合法获取边界。按闸门规则只修上述字段、CHGIS获取描述和已确认的迁移链接；不修改课程总纲，不重建其他系统。
